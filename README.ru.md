# Lumen

Русская версия документации. Английская версия: [README.md](README.md).

Telegram-бот в стиле Claude (прямой, тёплый, без лишних оговорок). Работает на Google Gemini, бесплатных моделях OpenRouter и Groq с автоматической маршрутизацией между ними. Умеет генерировать картинки, скачивать видео из TikTok (обычно без водяных знаков, с водяным знаком — в крайнем случае) и озвучивать текст. Запускается как вебхук-сервис на Hugging Face Spaces (Docker).

**Стек:** Python 3.13 · aiogram · FastAPI · google-genai · Docker

## Возможности

- **Автоматическая маршрутизация моделей.** Каждое сообщение уходит туда, где есть нужные возможности: обычный текст начинается с Gemma (самая большая бесплатная квота), затем Groq и OpenRouter; поиск в интернете и чтение ссылок — через Gemini. Каждый свежий запрос дополнительно получает внешние сниппеты (DuckDuckGo и Google News с датами публикации) для любой ответившей модели, включая резервные не-Gemini.
- **Стриминг ответов** с самокалибрующимся темпом печати: ответ появляется постепенно, а не крупными кусками.
- **Живой статус в стиле Claude.** В личных чатах поисковые запросы и запросы с медиа показывают таймлайн с искрой («Ищу в интернете», найденные источники, таймер ожидания) и завершаются свёрнутым блоком «Думал N с»; простые ответы получают одну курсивную строку. Ответы в личке отправляются обычными сообщениями, без Telegram-цитаты.
- **Защита от промпт-инъекций и утечки личности.** Детерминированный входной фильтр и выходные фильтры не дают боту раскрыть, какая модель или провайдер ответили.
- **Скачивание TikTok** (обычно без водяных знаков): видео, слайдшоу (включая «живые» фото-слайды) и оригинальный звук.
- **Генерация картинок** через Pollinations.ai. Модель подбирается по тексту запроса (аниме, фэнтези, реализм, быстрый набросок или общий дефолт).
- **Озвучка текста** через Gemini TTS.
- `/draw` и `/tts` работают и как обычные фразы в начале сообщения («нарисуй кота», «озвучь это»), без слэша.
- **Кнопки уточнения** для коротких вкусовых запросов без деталей («посоветуй фильм» → кнопки жанров вместо догадки).
- **Язык бота** (`/lang`): системные сообщения на 25 языках (по умолчанию английский). Ответы ИИ всегда следуют языку пользователя.
- **Персистентное состояние.** Необязательный Upstash Redis сохраняет историю чатов и счётчики квот между передеплоями.
- **Трекинг ошибок** через необязательный Sentry: секреты и локальные переменные вычищаются до отправки.

## Как это работает

Lumen — единый сервис FastAPI + aiogram. Telegram присылает обновления на вебхук; повторные доставки с тем же `update_id` игнорируются. Каждое сообщение проходит через цепочку моделей-кандидатов, собранную на лету по содержимому: вложения, ссылки и две лёгкие эвристики — «нужны ли свежие данные» и «тяжёлый ли запрос». Обычный текст начинается с Gemma, затем Groq и OpenRouter; поиск и чтение ссылок идут через Gemini; каждый свежий запрос получает внешние сниппеты DuckDuckGo/Google News для любого провайдера. Побеждает первый ответивший провайдер; если вся его цепочка упала, пробуется следующий. Модели, уже вернувшие 429 сегодня, роутер пропускает.

Код — модульный монолит. `bot.py` — точка входа и композиционный корень; остальное разбито по модулям: `lumen_admin.py` (FastAPI, секреты, admin/diag/export), `lumen_message_core.py` (ядро обработки сообщений), `lumen_routes.py` (вызовы LLM с фолбэком, `_run_route`), `lumen_streaming.py` (провайдер-агностичный стриминг), `lumen_status.py` (живой статус в стиле Claude), `lumen_search.py` (внешние сниппеты DuckDuckGo/Bing/Google News), `lumen_chat_state.py` (состояние чатов, квоты, блокировки), `lumen_commands.py` (команды, TTS/draw, кнопки выбора), `lumen_tiktok_flow.py` (отправка TikTok), `lumen_rich.py` (отправка: гости, Rich Messages, чанкинг), `lumen_media_flow.py` (скачивание вложений Telegram), `lumen_transport_calls.py` (сессии, ротация прокси, вызовы Telegram), `lumen_errors.py` (классификация ошибок моделей), `lumen_limits.py` (окно рейт-лимита, очередь кнопок), `lumen_router_config.py` (маршрутизация моделей), `lumen_formatting.py` (markdown → Telegram HTML и Rich Messages для таблиц/заголовков/математики), `lumen_security.py` (защита от инъекций и утечек), `lumen_message_parse.py` (ссылки, триггеры draw/tts, ссылки на медиа), `lumen_media.py` (mime-типы, разбор file_id), `lumen_images.py`, `lumen_tts.py`, `lumen_tiktok.py`, `lumen_telegram_transport.py`, `lumen_state_storage.py`, `lumen_typing_pace.py`, `lumen_model_speed.py` и `lumen_lang.py` (язык бота: системные сообщения на 25 языках). `lumen_devtrace.py` пишет опциональный JSONL-трейс (запросы, ответы, пассивный фон) для отладки промптов.

Подробнее о маршрутизации, стриминге, слоях защиты и загрузчике TikTok — в **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**.

## Деплой на Hugging Face Spaces

1. Запушь репозиторий в Space (`sdk: docker` уже указан во фронтматтере выше).
2. Задай обязательные секреты: `BOT_TOKEN`, `GEMINI_API_KEY` и `ADMIN_SECRET_SEED`. В проде бот не стартует без сида: админ-ключи не должны выводиться из токена бота.
3. Hugging Face соберёт образ из `Dockerfile` и запустит `python -u bot.py`.
4. При старте бот сам регистрирует вебхук. Если не вышло, в логах будет `[webhook] setWebhook failed`; зарегистрируй вручную:
   ```bash
   curl -H "Authorization: Bearer <ADMIN_PANEL_KEY>" https://<space-host>/webhook_url
   ```
   затем заполни `register_url_template`, который он вернёт (токен подставляй вручную, через curl — не открывай URL с токеном в браузере).
5. `WEBHOOK_SECRET` и `ADMIN_PANEL_KEY` детерминированно выводятся из `ADMIN_SECRET_SEED`. Получить их:
   ```bash
   curl -H "Authorization: Bearer <BOT_TOKEN>" https://<space-host>/admin_keys
   ```

Исходящие IP Hugging Face Spaces блокируются Telegram API на сетевом уровне, поэтому нужен небольшой прокси. См. [Прокси](#прокси).

## Настройка

Локально обязательны только `BOT_TOKEN` и `GEMINI_API_KEY`; на HF Space обязателен ещё `ADMIN_SECRET_SEED`. У остального есть разумные значения по умолчанию; полный справочник (адреса прокси, таймауты, хранилище, рейт-лимиты, настройки TikTok, конкурентность медиа) — в **[docs/ENVIRONMENT.md](docs/ENVIRONMENT.md)**.

## Прокси

Исходящие IP Hugging Face Spaces полностью блокируются Bot API Telegram, а TikWM (API TikTok, который использует бот) отвечает `403` на те же IP. Оба ограничения решает один небольшой прокси на Deno Deploy (исходник: `proxy/proxy.ts`):

```bash
TELEGRAM_API_BASE_URL=https://<proxy-domain>/fetch/api.telegram.org
TIKWM_API_BASE_URL=https://<proxy-domain>/fetch/www.tikwm.com
LUMEN_PROXY_SECRET=<случайная строка от 32 символов: без неё прокси отвечает 503, а бот падает на старте>
```

Прокси пропускает запросы только к явному списку хостов (`api.telegram.org`, `www.tikwm.com`, `tikwm.com`). Реализация — в `proxy/proxy.ts`, тесты — в `proxy/proxy_test.ts`.

## Диагностика

Все эндпоинты ниже требуют `Authorization: Bearer <ADMIN_PANEL_KEY>` (`/admin_keys` из шагов деплоя — исключение, ему нужен `BOT_TOKEN`):

| Эндпоинт | Назначение |
|---|---|
| `GET /diag` | Проверка исходящей сети (Telegram, Gemini, OpenRouter, TikWM, Pollinations и др.) из контейнера. |
| `GET /webhook_url` | Вычисленный URL вебхука и готовая ссылка для регистрации. |
| `GET /export_state` | Выгрузка всех историй чатов и счётчиков квот в JSON для ручного бэкапа. |
| `GET /devtrace?n=200` | Хвост dev-трейса (запросы, ответы, пассивный фон) в JSON. Нужен `DEV_TRACE=1`. |

`/logs` (команда Telegram, только владелец) присылает текущий `bot.log` с вычищенными секретами.

## Команды

`/start`, `/reset`, `/draw`, `/tts` и `/lang` показываются в меню команд Telegram:

| Команда | Доступ | Назначение |
|---|---|---|
| `/start` | всем | Краткое знакомство и список команд. |
| `/reset` | всем в личке; админам группы/владельцу в группах | Очищает историю диалога чата. |
| `/draw [описание]` | всем | Генерирует картинку. |
| `/tts [текст]` | всем | Озвучивает текст. |
| `/lang` | всем в личке; админам группы/владельцу в группах | Меню языка системных сообщений (ответы ИИ всегда следуют языку пользователя). |

Команды только для владельца намеренно не показываются в меню, чтобы не светить внутренние детали в группах:

| Команда | Доступ | Назначение |
|---|---|---|
| `/stats` | владелец, только личка | Число активных чатов, uptime, расход квот по моделям. |
| `/logs` | владелец, только личка | Присылает `bot.log` с вычищенными секретами. |
| `/selftest [gemini]` | владелец, только личка, не чаще раза в минуту | Живая проба голов маршрута (Groq, лёгкий OpenRouter, прокси Telegram, TikWM; Gemini — только с аргументом `gemini`). Успешные пробы тратят квоту. |
| `/ban <ID>` / `/unban <ID>` (или ответом на сообщение) | владелец, только личка | Блокировка/разблокировка пользователя по Telegram ID. Забаненные полностью игнорируются: без ответов, без фонового контекста, без счётчиков. Переживает рестарты. |
| `/banlist` | владелец, только личка | Показывает ID забаненных. |

В группах бот хранит последние сообщения (до 100, с общим лимитом символов) как контекст и отправляет их провайдерам моделей вместе с вопросом; `/reset` (админы группы/владелец) очищает их.

## Тесты

```bash
pip install -r requirements.txt -r requirements-dev.txt
pytest -v
```

Тесты лежат в `tests/` и повторяют разбиение на модули: `test_lumen_formatting.py`, `test_lumen_security.py`, `test_lumen_router_config.py`, `test_lumen_typing_pace.py`, `test_lumen_images.py`, `test_lumen_media.py`, `test_lumen_model_speed.py`, `test_lumen_search.py`, `test_lumen_status.py` и `test_lumen_devtrace.py` тестируют соответствующие модули напрямую, а `test_bot_admin.py`, `test_bot_commands.py`, `test_bot_routes.py`, `test_bot_search.py`, `test_bot_state.py`, `test_bot_streaming.py`, `test_bot_tiktok.py`, `test_bot_transport.py` и `test_bot_tts.py` покрывают `bot.py` по доменам (общие фейки — в `bot_test_helpers.py`). `test_eval_persona.py` покрывает фикстуры оценки персоны. `conftest.py` подставляет заглушки `BOT_TOKEN`/`GEMINI_API_KEY`/`BOT_LOG_PATH`, поэтому реальные секреты для тестов не нужны.

CI (`.github/workflows/ci.yml`) на каждый push и pull request, а также по недельному расписанию запускает `pyflakes` + `pytest` + `pip-audit` + `deno test`; успешный push запускает `sync-to-hf.yml`, который переносит коммит в Hugging Face Space (и отказывается перезаписывать прямой хотфикс на Space).

## Известные ограничения

- История чатов и счётчики квот переживают передеплой только при настроенном Upstash (см. [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md)); иначе они лежат на эфемерном диске контейнера и сбрасываются при каждой пересборке.
- Скачивание YouTube не поддерживается: исходящие IP Hugging Face Spaces блокируются на уровне TLS-рукопожатия. Просмотр и анализ видео по ссылке при этом работают.
- Скачивание TikTok зависит от неофициального API TikWM, а не от официального эндпоинта TikTok, и без прокси из Hugging Face Spaces вообще не работает.
- Автотесты стриминга используют моки; живой SSE вручную прогонялся через смоук-бота, но контролируемого интеграционного теста нет. Перед правкой стриминга прочитай ручной чек-лист в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Безопасность

О том, как сообщить об уязвимости, — в [SECURITY.md](SECURITY.md). Секреты вычищаются из логов и событий Sentry до отправки из контейнера; в публичных логах Space длинные числовые id чатов и пользователей хешируются. Вебхук проверяет секретный заголовок Telegram, ограничивает размер тела и игнорирует повторные доставки `update_id`. `ADMIN_SECRET_SEED` обязателен в проде, поэтому админ-ключи никогда не выводятся из токена бота.
